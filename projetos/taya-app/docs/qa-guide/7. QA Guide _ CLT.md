## Changelog

### 22/07/2026 — Jornada Multiconsentimento (substituição do fluxo de provedor único)

**Contexto:** o CLT passou de um modelo de provedor único (Celcoin — descontinuado) para jornada multiconsentimento com Bull, C6, V8 e Paraná Banco (oculto por flag).

**Telas novas — testar do zero:**

| Rota | O que testar |
|------|-------------|
| `/consignado-clt/provedores` | Seleção de parceiro via radio button. Badges de status (Consultando/Oferta encontrada/Sem oferta/Tempo esgotado). Botão "Ver minhas ofertas" só habilita com ao menos 1 status `oferta` ou `sem_oferta` |
| `/consignado-clt/consentimento/:provedor` | Termo por parceiro em container scrollável. Checkbox obrigatório. Link "Não quero consultar" volta para provedores sem aceitar. Guard: URL inválida redireciona para `/provedores` |
| `/consignado-clt/redirecionando/:provedor` | Tela de transição 3s → abre `consent_url` em nova aba → volta para provedores com status `aguardando`. Todos os parceiros são externos |
| `/consignado-clt/ofertas` | N cards comparáveis. Labels "Maior valor"/"Maior prazo" calculados dinamicamente. Card e botão "Ver condições" clicáveis. Drawer com detalhes + "Escolher esta oferta" → simulador |

**Telas atualizadas:**

- **Landing:** CTA agora aponta para `/provedores` (antes `/loading`)
- **Simulador:** parcelas em ordem **crescente** (era decrescente). Badge do parceiro visível
- **Revisão:** badge do parceiro + state propagado corretamente para telas seguintes
- **Confirmação:** campo "Parceiro" adicionado ao resumo

**Tela removida do fluxo principal:** `/consignado-clt/oferta` (oferta única) — mantida como rota legada, fora do fluxo ativo

**Painel — "Para você agora":**
- Card de valor fixo (ex: "R$ 32.533,83") **removido**
- Novo estado `?clt=consulta_liberada` — card verde "Suas ofertas estão prontas" → `/ofertas`. Some ao entrar em `/revisao`

**Parâmetros de URL novos (DESIGN ONLY):**

```
/consignado-clt/provedores?provedores=nenhum|parcial|todos|expirado
/consignado-clt/consentimento/bull|c6|v8|parana
/consignado-clt/ofertas?qtd=0|1|2|3
/painel?clt=consulta_liberada
```

**Cenários de erro a testar:**
- `?qtd=0` em `/ofertas` — estado vazio com cross-sell
- `?provedores=expirado` — badge "Tempo esgotado" + "Tentar novamente"
- URL inválida em `/consentimento/xyz` — redireciona para `/provedores`
