# QA Guide — Dashboard (Home)
**seutudo. · Taya Tech · Confidencial**
Versão 1.0 — Maio 2026

---

## Visão Geral

A dashboard é a tela principal do app após autenticação. Exibe recomendações proativas, cards de produto personalizados conforme os interesses selecionados no onboarding, box de suporte e selos de conformidade.

```
Header laranja (saudação + carrossel de recomendações)
→ Cards de produto (grid 2x2 no desktop, coluna no mobile)
→ Box de dúvidas
→ Selos LGPD / Banco Central / Criptografado
```

Rota: `/painel`
Acesso: apenas usuários autenticados

---

## Como usar este guia

Cada seção cobre um componente da dashboard. Para cada um:
- **Caso de sucesso (Happy Path)**: comportamento esperado em condições normais
- **Casos alternativos (Forks)**: condições de exceção com comportamento esperado

## Carrossel de Recomendações ("Para você agora")

### Contexto
Cards proativos dentro do header laranja. Cada card pode ser dispensado pelo usuário. Dismissals persistidos em localStorage.

### Happy Path
| Passo | Ação | Resultado esperado |
|-------|------|--------------------|
| C.1 | Dashboard carregada com recomendações ativas | Carrossel exibido abaixo da saudação, dentro do header |
| C.2 | Label "PARA VOCÊ AGORA" visível | Texto em branco/opaco acima dos cards |
| C.3 | Cards com scroll horizontal | Swipe lateral funciona no mobile; mouse drag/scroll no desktop |
| C.4 | Usuário clica no CTA de um card | Navega para a rota definida no card |
| C.5 | Usuário clica no X de um card dispensável | Card some com animação de saída (Framer Motion); dismissal salvo em localStorage |
| C.6 | Usuário reabre o app após dispensar card | Card dispensado não reaparecer |
| C.7 | Card não dispensável (ex: parcela vencendo) | Ícone X ausente; card sempre visível |

### Forks
| ID | Cenário | Como reproduzir | Resultado esperado |
|----|---------|-----------------|-------------------|
| FC.1 | Todas as recomendações dispensadas | Dispensar todos os cards | Carrossel oculto; seção "Para você agora" desaparece |
| FC.2 | localStorage indisponível | Bloquear localStorage no browser | Dismissal não persiste; cards reaparecem no reload — comportamento aceitável sem crash |
| FC.3 | Animação de dismiss travada | Clicar X rapidamente em múltiplos cards | Cada card some individualmente sem afetar os demais |
| FC.4 | Card com rota inválida | Simular `rota: "/produto-inexistente"` | Navega para rota; app exibe 404 ou redireciona para `/painel` |

## Cards de Produto

### Contexto
Exibidos abaixo do header. Renderizados com base nos produtos selecionados no onboarding (`interests`). O primeiro produto é marcado como "Principal".

### Happy Path
| Passo | Ação | Resultado esperado |
|-------|------|--------------------|
| P.1 | Dashboard carregada com 1+ produtos selecionados | Cards renderizados na ordem: produto principal primeiro |
| P.2 | Card principal (idx === 0) | Badge "Principal", highlight de valor em laranja, CTA com outline laranja |
| P.3 | Cards secundários (idx > 0) | Sem badge, CTA neutro com borda cinza |
| P.4 | Foto de ICP no canto direito de cada card | Imagem PNG com fundo transparente exibida sem artefatos |
| P.5 | Usuário clica no CTA de um produto | Navega para a rota do produto (`/saque-facil`, etc.) |
| P.6 | Toggle de privacidade ativo | Valores monetários nos cards exibidos como `R$ ••••` |
| P.7 | Toggle de privacidade inativo | Valores monetários exibidos normalmente |

### Forks
| ID | Cenário | Como reproduzir | Resultado esperado |
|----|---------|-----------------|-------------------|
| FP.1 | Nenhum produto selecionado | Simular `interests: []` | Área de cards vazia; exibir mensagem "Explore nossos produtos" com CTA para seleção |
| FP.2 | Apenas 1 produto selecionado | Selecionar só 1 produto no onboarding | Card único exibido como "Principal" sem grid |
| FP.3 | Imagem do produto não carrega | Simular erro 404 na imagem | Fallback com fundo `#F5F4F2` sem quebrar o layout |
| FP.4 | Produto fake door clicado | Clicar em produto "Em breve" | Navegar para tela educacional do produto ou exibir modal "Em breve" |
| FP.5 | 3 produtos selecionados no desktop | Selecionar todos no onboarding | Grid 2x2 com terceiro card ocupando linha inteira ou metade |

## Forks Transversais (dashboard inteira)

| ID | Cenário | Comportamento esperado |
|----|---------|----------------------|
| FT.1 | Perda de conexão na dashboard | Toast ou banner: "Sem conexão." Conteúdo já carregado permanece visível. |
