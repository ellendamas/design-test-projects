## Visão Geral da Jornada

Crédito pessoal sem garantia, ofertado em parceria com a Zema Financeira. Diferente do Consignado CLT e do FGTS, não exige vínculo empregatício ativo nem saldo de FGTS — é o produto mais inclusivo do portfólio Pode Já.

```
Landing → Dados básicos → Loading elegibilidade → [Inelegível | Simulador] → Revisão →
Dados do tomador → Conta bancária → Loading formalização →
[Reprovada | Pendente | Assinatura] → Confirmação → Contrato ativo
```

Rota principal: `/credito-pessoal`

### 22/07/2026 — Ajustes de segurança, fluxo e dados

**1. Nova tela: "Em análise" (`/credito-pessoal/em-analise`)**

Inserida entre `/formalizando` e `/assinatura`. O fluxo correto agora é:

Formalização → Em análise → Assinatura

A tela exibe loading com copy "Sua proposta está em análise" enquanto aguarda a Zema liberar o link de assinatura. Timer mock de 5s → navega para `/assinatura`.

Parâmetros:

```
?resultado=pronto → navega para /assinatura após 2s
?resultado=pendente → navega para /pendente após 2s
```

**2. Celular e e-mail bloqueados na tela de dados (`/credito-pessoal/dados`)**

Campos de celular e e-mail agora exibem ícone de cadeado (mesmo padrão de CPF e nome). Não é mais possível alterar esses campos nesta tela.

Motivo: celular é usado como 2FA — edição aqui seria brecha de segurança.

**3. Valor máximo corrigido no simulador (`/credito-pessoal/simulador`)**

`valorMaximo` corrigido de R$ 5.000,00 para **R$ 3.000,00** (teto real da Zema).
Exibição: "Máx. R$ 3.000,00" no campo de valor. Input limitado ao novo máximo.

**4. PEP condicional com subcampos (`/credito-pessoal/dados-tomador` — step 3)**

A pergunta agora é: "Você é uma Pessoa Politicamente Exposta (PEP) ou tem relação com uma?"

- Resposta **Não**: nenhum campo adicional, avança normalmente
- Resposta **Sim**: abre seletor de tipo ("Eu sou a PEP" / "Tenho relação com uma PEP") + campos condicionais:
  - Ambos os tipos: nome, data de início do cargo, função (texto livre)
  - Apenas "Tenho relação": campo adicional de tipo de relação (Familiar / Representante legal / Outros)
  - Quando "Eu sou a PEP": campo nome autopreenchido com nome do usuário e **bloqueado** (não editável)

Parâmetros de URL para testar:

```
?step=3&pep=nao → Não selecionado
?step=3&pep=proprio → Sim + "Eu sou a PEP" + campos abertos (nome bloqueado)
?step=3&pep=relacao → Sim + "Tenho relação" + todos os campos incluindo tipo de relação
```

**5. Aviso Zema na landing — destaque reduzido**

O bloco de parceria Pode Já × Zema continua presente mas com menor destaque visual (padding reduzido, sem sombra, logos menores, texto descritivo removido).
