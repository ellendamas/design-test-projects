# QA Matriz de Validacao Geral — seutudo.

Versao inicial para uso do time de QA. Este arquivo deve ser atualizado continuamente.

## Como usar
- `Entrada`: dado digitado no campo.
- `Resultado`: avancar, bloquear ou exibir erro.
- `Mensagem esperada`: texto exato na interface.

## 1) Login (`/acesso`)

### CPF + senha
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| CPF valido + senha `142536` | Avanca para escolha de canal OTP | - |
| CPF invalido (ex: `111.111.111-11`) | Bloqueia | `CPF invalido. Verifique o numero.` |
| CPF `000.000.000-00` | Bloqueia | `CPF nao encontrado. Verifique ou crie sua conta.` |
| Senha diferente de `142536` | Bloqueia e limpa campo senha | `Senha incorreta. Tente novamente.` |
| 5 tentativas de senha errada seguidas | Bloqueia temporariamente | `Conta temporariamente bloqueada. Tente novamente em 60 segundos.` |

### OTP login
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| 6 digitos preenchidos | Botao `Confirmar` habilita | - |
| Menos de 6 digitos | Botao `Confirmar` desabilitado | - |

## 2) Recuperar senha (`/recuperar-senha/*`)

### RS1 — CPF
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| CPF valido e cadastrado | Avanca para `/recuperar-senha/canal` | - |
| CPF invalido | Bloqueia | `CPF invalido. Verifique e tente novamente.` |
| CPF `000.000.000-00` | Bloqueia | `CPF nao encontrado. Verifique ou faca seu cadastro.` |

### RS2 — Canal
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| Nenhum canal selecionado | Botao desabilitado | - |
| Canal selecionado + clicar `Enviar codigo` | Avanca para OTP | `Codigo enviado via [canal]!` |

### RS3 — OTP
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| `123456` | Avanca para nova senha | - |
| `000000` | Bloqueia e libera reenvio imediato | `Codigo expirado. Solicite um novo codigo.` |
| Qualquer outro codigo de 6 digitos | Bloqueia e limpa campos | `Codigo incorreto. Verifique e tente novamente.` |
| 3 erros seguidos | Bloqueio temporario | `Muitas tentativas. Aguarde 60 segundos para tentar novamente.` |

### RS4 — Nova senha
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| Senha >= 6, diferente da anterior, confirmacao igual | Sucesso e redireciona para `/acesso` | `Senha alterada com sucesso!` |
| Senha `< 6` | Botao desabilitado | - |
| Confirmacao diferente | Bloqueia | `As senhas nao coincidem.` |
| Senha `senha123` | Bloqueia | `A nova senha deve ser diferente da anterior.` |

## 3) Onboarding (`/cadastro`)

### Passo 2 — CPF
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| CPF valido | Avanca | - |
| CPF invalido com 11 digitos | Bloqueia | `CPF invalido. Verifique o numero e tente novamente.` |

### Passo 4 — senha numerica
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| `142536` | Avanca | - |
| `123456` | Bloqueia | `Evite sequencias como 123456 ou numeros repetidos.` |
| `000000` | Bloqueia | `Evite sequencias como 123456 ou numeros repetidos.` |
| Menos de 6 digitos | Botao desabilitado | - |

## 4) Minha conta

### Meus dados (`/minha-conta/meus-dados`)
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| E-mail valido + celular valido | Salva e volta para indice | `Dados atualizados.` |
| E-mail sem formato valido | Bloqueia | `Informe um e-mail valido.` |
| Celular incompleto | Bloqueia | `Informe um celular valido com DDD.` |
| E-mail `existente@seutudo.com.br` | Bloqueia | `Este e-mail ja esta em uso.` |

### Alterar senha (`/minha-conta/alterar-senha`)
| Entrada | Resultado | Mensagem esperada |
|---|---|---|
| Atual `142536` + nova valida + confirmacao igual | Salva com sucesso | `Senha alterada com sucesso.` |
| Atual diferente de `142536` | Bloqueia | `Senha atual incorreta. Tente novamente.` |
| Nova igual atual | Bloqueia | `A nova senha deve ser diferente da atual.` |
| Nova diferente da confirmacao | Bloqueia | `As senhas nao coincidem.` |
| Nova fraca (ex: `123456`) | Bloqueia | `Nao use sequencias simples como 123456.` |

## 5) Saque Facil (`/saque-facil`)

| Campo | Entrada | Resultado esperado |
|---|---|---|
| RG | Formato invalido / repetido | Nao avanca da etapa |
| Data de nascimento | Menor de 18, futura ou invalida | Nao avanca da etapa |
| Cartao | Numero invalido (Luhn), vencido, CVV curto | Nao avanca da etapa |

## Observacoes para QA
- Este prototipo usa simulacoes locais para varios cenarios.
- Regras de backend (ex.: bloqueios por tempo de servidor, unicidade real, blacklist) devem ser validadas depois em ambiente integrado.
- Atualizar este documento a cada nova regra de validacao implementada.
